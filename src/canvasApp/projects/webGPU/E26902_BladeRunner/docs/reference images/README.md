## Criterios de revisión continuados

- Piedra: variación mineral visible sin ruido fino dominante; juntas legibles sin contorneado luminoso uniforme.
- Cuero y nogal: conservar profundidad oscura y distinguirlos por rugosidad y detalle; evitar aclararlos globalmente para compensar una luz insuficiente.
- Bronce/latón y cristal: brillos localizados; comprobar la cristalería blanquecina actual bajo el entorno de referencia.
- Pavimento: base oscura, juntas y desgaste conservados, reflejos largos con rugosidad; revisar el gran brillo claro actual.
- Exterior y atmósfera: recuperar lectura del edificio, profundidad y halo solar; ajustar por separado materiales, luz y volumen.

Las capturas de revisión de cada entrega deben indicar qué aspecto se valida y cuáles siguen pendientes. La fase 3.1 valida mapas/canales y conexiones; no cambia aún la iluminación ni iguala estos fotogramas. La distribución geométrica sigue referenciada a la plantilla y al modelo aprobados en fase 2.
